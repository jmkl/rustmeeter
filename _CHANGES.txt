RustMeeter update: parametric EQ (core + CLI + GUI)

Extract into your workspace root (the folder with the top-level Cargo.toml), overwrite when asked.
Nothing to delete. Then:

  cargo test -p rustmeeter-core        # checks the filter responses (new, optional)
  cargo build --release --features gui # or however you normally build the GUI

Files (paths are relative to the workspace root):
  - README.md   
  - crates/rustmeeter-cli/src/main.rs   
  - crates/rustmeeter-core/src/engine.rs   
  - crates/rustmeeter-core/src/eq.rs   (NEW)
  - crates/rustmeeter-core/src/lib.rs   
  - crates/rustmeeter-core/src/mixer.rs   
  - crates/rustmeeter-core/src/params.rs   
  - crates/rustmeeter/src/main.rs   

Breaking API change in rustmeeter-core: the fixed 3-band EQ is gone
(Params::eq_db / set_eq_db, EQ_BANDS, EQ_BAND_NAMES, EQ_RANGE_DB, StripView::eq_db).
Replaced by Params::eq() / set_eq() / update_eq() and StripView::eq (EqSettings).
